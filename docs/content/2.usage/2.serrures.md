---
title: Serrures et autorisations d'accès
description: Serrures connectées d'un lieu et codes clavier temporaires.
---

Un administrateur associe chaque serrure à un lieu (**Administration → Serrures** ; « Synchroniser » y ajoute les serrures du compte Nuki global). Une serrure peut aussi venir d'un connecteur du lieu (Home Assistant, Homey).

Une **autorisation d'accès** est un code clavier temporaire : un lieu, une serrure, un libellé, une période de validité. Elle est d'abord **prévue** (code réservé, rien n'est écrit sur la serrure), puis **envoyée à la serrure uniquement sur ton clic**, et peut être **révoquée**. Une application (un PMS) peut en créer avec une référence externe (`externalRef`) : une seconde demande identique renvoie la même autorisation.

Le jeton Nuki doit avoir le droit `smartlock.auth` pour créer des codes.
