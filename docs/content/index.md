#description
Rocket Place gère tes **lieux** (logements, locaux, terrains…) sans PMS : **serrures connectées** et **autorisations d'accès**, **domotique** par connecteurs, **documents** dans Rocket Cloud et **stock** de consommables. Le ménage est dans Rocket Clean. Un PMS peut le piloter par l'API.
