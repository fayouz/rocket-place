title: API du domaine
description: Logements, réservations, conversations, serrures et codes.
---

Toutes les routes demandent un utilisateur connecté (jeton JWT) ou une application externe (`Authorization: Bearer rpl_…` et `X-Impersonate-User`). Envoyer `Accept: application/json`.

| Méthode | Route | Rôle |
|---|---|---|
| GET | `/api/properties` | Logements |
| GET · PATCH | `/api/properties/{id}` | Un logement ; modification (nom, couleur) : administrateur |
| POST | `/api/properties/sync` | Crée les logements depuis Lodgify et enregistre les serrures Nuki (administrateur) |
| GET | `/api/properties/{id}/bookings` | Réservations (60 derniers jours et à venir) avec leur code clavier |
| GET | `/api/properties/{id}/bookings/{bookingId}/pricing` | Valeur et détail du prix |
| GET · POST | `/api/properties/{id}/bookings/{bookingId}/conversation` | Conversation ; réponse `{"text", "messageId": "<uuid>"}` |
| GET | `/api/properties/{id}/locks` · `/api/locks` | Serrures (état, batterie, historique) |
| PUT | `/api/locks/{nukiId}` | Logement ouvert par la serrure `{"property": "<uuid>" \| null}` (administrateur) |
| GET | `/api/properties/{id}/codes` | Codes clavier des séjours à venir |
| POST | `/api/codes/{bookingId}` | Crée le code sur la serrure (action réelle) |
| GET | `/api/properties/{id}/timeline` · `/api/timeline` | Timeline (`?past=` jours, défaut 3 ; `?future=`, défaut 45) |

## Ménage

Utilisable par une application pour elle-même (`Authorization: Bearer rpl_…` sans `X-Impersonate-User`), par exemple un PMS qui crée un ménage après chaque départ.

| Méthode | Route | Rôle |
|---|---|---|
| GET | `/api/cleanings` | Ménages d'un jour et ménages en retard (`?date=AAAA-MM-JJ`, défaut aujourd'hui, `all` sans filtre ; `?mine=1` ; `?place=<uuid>`) |
| GET | `/api/places/{id}/cleanings` | Ménages d'un lieu |
| POST | `/api/places/{id}/cleanings` | Planifie `{"scheduledAt", "dueAt"?, "label"?, "assigneeEmail"? \| "assigneeId"?, "notes"?, "externalRef"?}` (administrateur ou application). Idempotent par `externalRef` (unique par lieu) : 201 à la création, 200 avec le ménage existant ensuite |
| GET · PATCH · DELETE | `/api/cleanings/{id}` | Un ménage. PATCH : `status` (`todo`, `in_progress`, `done`, `cancelled`), `notes`, `checklist: [{"index", "done"}]` pour la personne attribuée ; `label`, `scheduledAt`, `dueAt`, `assigneeEmail`/`assigneeId` (null = personne) et DELETE : administrateur ou application |
| POST | `/api/cleanings/{id}/photos` | Multipart `file` + `moment` (`before`, `after`, `damage`) |
| POST | `/api/cleanings/{id}/stock` | `{"stockLevelId", "level": "ok" \| "low" \| "empty"}` : change le niveau du lieu et le note sur le ménage |
| GET · PUT | `/api/places/{id}/cleaning-checklist` | Modèle de checklist du lieu ; PUT `{"items": ["Draps changés", …]}` (administrateur ou application) |

Exemple (PMS, après un départ) :

```bash
curl -X POST https://place.example.org/api/places/<uuid>/cleanings \
  -H 'Authorization: Bearer rpl_…' -H 'Accept: application/json' -H 'Content-Type: application/json' \
  -d '{"scheduledAt":"2026-10-05T11:00:00+02:00","dueAt":"2026-10-05T16:00:00+02:00","label":"Ménage après Sofia Rossi","externalRef":"booking-42"}'
```
