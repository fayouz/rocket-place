---
title: API du domaine
description: Lieux, serrures, autorisations d'accès, connecteurs, documents et ménage.
---

Toutes les routes demandent un utilisateur connecté (jeton JWT) ou une application externe (`Authorization: Bearer rpl_…`, avec ou sans `X-Impersonate-User`). Envoyer `Accept: application/json`. Une application sans impersonation (un PMS pour lui-même) accède aux lieux, serrures, autorisations d'accès, documents et ménages, pas aux comptes ni aux réglages.

## Lieux, serrures, accès

| Méthode | Route | Rôle |
|---|---|---|
| GET · POST | `/api/places` | Lieux ; création : administrateur ou application |
| GET · PATCH | `/api/places/{id}` | Un lieu (nom, adresse, couleur, coordonnées) |
| GET | `/api/locks` · `/api/places/{id}/locks` | Serrures (état, batterie, historique) |
| POST | `/api/locks/sync` | Enregistre les serrures du compte Nuki global (administrateur) |
| PUT | `/api/locks/{nukiId}` | Lieu ouvert par la serrure `{"place": "<uuid>" \| null}` (administrateur) |
| GET · POST | `/api/places/{id}/access-grants` | Autorisations d'accès ; POST `{"lockId", "label", "validFrom", "validUntil", "externalRef"?}` les **prévoit** seulement (idempotent par `externalRef`) |
| POST | `/api/access-grants/{id}/send` · `/revoke` | Écrit le code sur la serrure (action réelle) · le retire |

## Connecteurs, domotique, documents

| Méthode | Route | Rôle |
|---|---|---|
| GET | `/api/plugins` | Catalogue des plugins |
| GET · POST | `/api/places/{id}/connectors` | Connecteurs d'un lieu (administrateur) |
| PATCH · DELETE | `/api/connectors/{id}` · POST `/api/connectors/{id}/test` | Modifier, supprimer, tester un connecteur |
| GET | `/api/places/{id}/domotique` | Cartes remontées par les connecteurs du lieu |
| GET | `/api/places/{id}/documents` | Dossier Rocket Cloud du lieu (`?folder=folder:<id>`) |
| POST | `/api/places/{id}/documents/folders` · `/upload` | Nouveau dossier · envoi (multipart `file`) |
| PATCH · DELETE | `/api/places/{id}/documents/{itemId}` | Renommer / déplacer · supprimer |
| GET | `/api/places/{id}/documents/{itemId}/content` | Contenu d'un fichier |

## Ménage

Utilisable par une application pour elle-même (`Authorization: Bearer rpl_…` sans `X-Impersonate-User`), par exemple un PMS qui crée un ménage après chaque départ.

| Méthode | Route | Rôle |
|---|---|---|
| GET | `/api/cleanings` | Ménages d'un jour et ménages en retard (`?date=AAAA-MM-JJ`, défaut aujourd'hui, `all` sans filtre ; `?mine=1` ; `?place=<uuid>`) |
| GET | `/api/places/{id}/cleanings` | Ménages d'un lieu |
| POST | `/api/places/{id}/cleanings` | Planifie `{"scheduledAt", "dueAt"?, "label"?, "assigneeEmail"? \| "assigneeId"?, "notes"?, "externalRef"?}` (administrateur ou application). Idempotent par `externalRef` (unique par lieu) : 201 à la création, 200 avec le ménage existant ensuite. Avec une personne : e-mail d'attribution |
| GET · PATCH · DELETE | `/api/cleanings/{id}` | Un ménage. PATCH : `status` (`todo`, `in_progress`, `done`, `cancelled`), `notes`, `checklist: [{"index", "done"}]` pour la personne attribuée ; `label`, `scheduledAt`, `dueAt`, `assigneeEmail`/`assigneeId` (null = personne) et DELETE : administrateur ou application |
| POST | `/api/cleanings/{id}/photos` | Multipart `file` + `moment` (`before`, `after`, `damage`) |
| GET · POST · DELETE | `/api/cleanings/{id}/link` | Lien secret sans compte `{"url", "path", "expiresAt"}` : GET le crée au besoin, POST le régénère (l'ancien ne marche plus), DELETE le révoque |
| GET · PUT | `/api/places/{id}/cleaning-checklist` | Modèle de checklist du lieu ; PUT `{"items": ["Draps changés", …]}` (administrateur ou application) |
| GET | `/api/cleaning-assignees` | Comptes actifs à qui attribuer un ménage (administrateur) |
| GET · PUT | `/api/cleaning-settings` | E-mails `{"assignment", "late", "summary"}` (booléens, administrateur) |

### Lien secret (public, sans compte)

Limité à un seul ménage, 120 requêtes par minute et par IP (10 jetons invalides par minute, puis 429), réponses `Cache-Control: no-store` et `X-Robots-Tag: noindex`. Valable jusqu'au lendemain de l'échéance (ou du jour prévu).

| Méthode | Route | Rôle |
|---|---|---|
| GET · PATCH | `/api/public/cleaning/{token}` | Le ménage (avec `expiresAt`) ; PATCH `status`, `notes`, `checklist` (le reste est ignoré) |
| POST | `/api/public/cleaning/{token}/photos` | Multipart `file` + `moment` |
| GET | `/api/public/cleaning/{token}/photos/{fileId}` | Contenu d'une photo de ce ménage |

Exemple (PMS, après un départ) :

```bash
curl -X POST https://place.example.org/api/places/<uuid>/cleanings \
  -H 'Authorization: Bearer rpl_…' -H 'Accept: application/json' -H 'Content-Type: application/json' \
  -d '{"scheduledAt":"2026-10-05T11:00:00+02:00","dueAt":"2026-10-05T16:00:00+02:00","label":"Ménage après Sofia Rossi","externalRef":"booking-42"}'
```
