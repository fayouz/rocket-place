title: API du domaine
description: Lieux, serrures, autorisations d'accès, connecteurs, documents et stock.
---

Toutes les routes demandent un utilisateur connecté (jeton JWT) ou une application externe (`Authorization: Bearer rpl_…`, avec ou sans `X-Impersonate-User`). Envoyer `Accept: application/json`. Une application sans impersonation (un PMS pour lui-même) accède aux lieux, serrures, autorisations d'accès, documents et stock, pas aux comptes ni aux réglages.

## Lieux, serrures, accès

| Méthode | Route | Rôle |
|---|---|---|
| GET · POST | `/api/places` | Lieux ; création : administrateur ou application |
| GET · PATCH | `/api/places/{id}` | Un lieu (nom, adresse, couleur, coordonnées) |
| GET | `/api/locks` · `/api/places/{id}/locks` | Serrures (état, batterie, historique) |
| POST | `/api/locks/sync` | Enregistre les serrures du compte Nuki global (administrateur) |
| PUT | `/api/locks/{nukiId}` | Lieu ouvert par la serrure `{"place": "<uuid>" \| null}` (administrateur) |
| GET · POST | `/api/places/{id}/access-grants` | Autorisations d'accès ; POST `{"lockId", "label", "validFrom", "validUntil", "externalRef"?}` les **prévoit** seulement (idempotent par `externalRef`) |
| POST | `/api/access-grants/{id}/send` · `/revoke` | Écrit le code sur la serrure (action réelle) · le retire |

## Connecteurs, domotique, documents, stock

| Méthode | Route | Rôle |
|---|---|---|
| GET | `/api/plugins` | Catalogue des plugins |
| GET · POST | `/api/places/{id}/connectors` | Connecteurs d'un lieu (administrateur) |
| PATCH · DELETE | `/api/connectors/{id}` · POST `/api/connectors/{id}/test` | Modifier, supprimer, tester un connecteur |
| GET | `/api/places/{id}/domotique` | Cartes remontées par les connecteurs du lieu |
| GET | `/api/places/{id}/documents` | Dossier Rocket Cloud du lieu (`?folder=folder:<id>`) |
| POST | `/api/places/{id}/documents/folders` · `/upload` | Nouveau dossier · envoi (multipart `file`) |
| PATCH · DELETE | `/api/places/{id}/documents/{itemId}` | Renommer / déplacer · supprimer |
| GET | `/api/places/{id}/documents/{itemId}/content` | Contenu d'un fichier |
| CRUD | `/api/stock-items` · `/api/stock-levels` | Catalogue d'articles · niveau par lieu (`?place=/api/places/<uuid>`) |

Le ménage (`/api/places/{id}/cleanings`, `/api/cleanings/…`, lien secret `/api/public/cleaning/…`) a quitté Rocket Place : même API dans [Rocket Clean](https://github.com/fayouz/rocket-clean) (jeton `rcl_…`), qui lit ici `/api/places` et `/api/stock-levels`.
