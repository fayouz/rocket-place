
Ou sur GitHub : **Code → Codespaces → Create codespace** (rien à installer, voir `demo/README.md`).

| Compte | Mot de passe |
|---|---|
| `alice@example.org` (gestionnaire) | `demo-alice-password` |
| `admin@example.org` (administrateur) | `demo-admin-password` |

La démo contient deux lieux fictifs (« Le port » et « Les vignes »), une serrure par lieu, et des articles de stock. Aucun jeton Nuki ni Rocket Cloud : aucun code n'est écrit.

## Scénario conseillé

1. **Tous les lieux → Le port** : onglets Serrures, Domotique, Documents, Stock.
2. Onglet **Serrures** : état et batterie, prévoir une autorisation d'accès (l'envoi à la serrure est simulé).
3. Onglet **Stock** : passer un article en Bas ou Vide.
