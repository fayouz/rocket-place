```bash

```

Ou sur GitHub : **Code → Codespaces → Create codespace** (rien à installer, voir `demo/README.md`).

| Compte | Mot de passe |
|---|---|
| `alice@example.org` (gestionnaire) | `demo-alice-password` |
| `admin@example.org` (administrateur) | `demo-admin-password` |

La démo contient deux lieux fictifs (« Le port » et « Les vignes »), une serrure par lieu, des articles de stock et des ménages autour d'aujourd'hui. Aucun jeton Nuki, Rocket Cloud ni Rocket Mailer : aucun code n'est écrit, aucun e-mail ne part.

## Scénario conseillé

1. **Tous les lieux → Le port** : onglets Serrures, Domotique, Documents, Stock, Ménage.
2. Onglet **Serrures** : état et batterie, prévoir une autorisation d'accès (l'envoi à la serrure est simulé).
3. Onglet **Ménage** (admin) : planifier un ménage pour Alice, copier son **lien sans compte** et l'ouvrir dans une fenêtre privée.
4. Menu **Ménage** (en Alice, sur téléphone) : commencer, cocher, photographier, mettre le stock à jour, terminer.
